# VoiceLedger v0.1.0 preview

A local Windows transcription and speaker-review application, published as GPL-3.0-only source.

Download the source archive, install Node.js 24, run `Setup.cmd`, then `Launch.cmd`. The browser interface opens on localhost. No desktop installer is included yet.

This preview includes English and Bulgarian menus, three CPU transcription modes, Community-1 speaker analysis, original-audio playback, waveforms, confirmed speaker references, cross-recording comparisons, reversible corrections, an optional Codex correction assistant, resumable jobs, and TXT/SRT/CSV/JSON exports. Private runtime data stays outside the repository. Models download separately after you accept their access conditions.

The included LibriSpeech demo is attributed under CC BY 4.0. Its precomputed transcript and speaker labels come from dataset annotations; it is not a model accuracy benchmark.

The review screen gives the transcript most of the available space. Start review, play one excerpt, edit its name and text, then save and move to the next. Advanced corrections stay available in a collapsed section. Narrow windows use a full-screen editor with a clear return action.

Validation on the development Windows machine: 20 Python tests, two interface tests, eight browser tests, production build, Windows setup, complete decoding of three long source recordings, all three ASR modes on a one-minute Bulgarian excerpt, real public-audio processing/cancel/resume/reference comparisons, and fictional English/Bulgarian Codex requests. Browser checks include the combined name/text save flow, short windows, and a 319 px app pane in both interface languages. The repository's Windows workflow repeats account-free automated checks.

Bulgarian word error rate and speaker attribution targets still require a human-reviewed reference. A short public test initially merged two of three readers; a minimum-speaker hint recovered the count. Count alone does not establish correct attribution. Similarities are not probabilities, and all identity matches require confirmation. Whole-recording memory use and multi-hour throughput are not established by short smoke tests.

Read the setup instructions, measured results and limitations before processing a large library. This is a preview pending the private quality pilot, not a claim that the Bulgarian acceptance targets have been met.
